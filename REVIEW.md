# Review notes

Sebastian writes here. This is the channel for anything longer than a sentence:
a chapter that does not convince, a number that looks wrong, a section that
belongs somewhere else, a decision to reverse.

Claude reads this file at the start of every book session, before touching a
chapter, works the open items from the top, and moves each one to **Done** with
the chapter or commit it landed in. Nothing is deleted.

Why a file and not the chat: a session gets compacted, and long comments in the
chat are the first thing lost. This survives.

## How to write an item

```
### 05 · Covariance — the four routes arrive too late
Everything before them reads as diagnosis...
**Verdict:** move the routes up, keep the diagnosis to two paragraphs.
```

The heading is the chapter and a title. The body can be as long as you like.
The **Verdict** line says what you want to happen, so there is no guessing.

Short, local remarks belong in the `.qmd` itself, at the spot:

```
<!-- SS: this sentence claims more than the table shows -->
```

Those are grepped when the chapter is next opened and answered in place.
