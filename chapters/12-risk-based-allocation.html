14  Risk-Based Allocation

The question. What if you allocate risk instead of capital?

Every portfolio so far has been described by how much money sits in each position. That is not the same as how much risk sits in each position, and on this universe the two are very far apart: Section 9.1’s minimum-variance portfolio puts most of its capital in one series and — as this chapter will measure — nearly all of its risk there too.

Allocating risk instead is an old idea with a clean definition, a cheap approximation, and an implementation in PortfolioAnalytics that does not work. All three are worth knowing.

R  <- as_xts_pm(sim_class_returns_monthly, date, class, return)
R  <- R[, !grepl("money_market", colnames(R))]
Re <- R - sim_riskfree_monthly$return
S  <- stats::cov(Re)
N  <- ncol(Re)

14.1 What you need

14.1.1 Risk contributions

Portfolio variance decomposes exactly. Each asset’s share is its weight times its marginal contribution, and the shares sum to one.

risk_contribution <- function(w, S) {
  marginal <- as.numeric(S %*% w)
  (w * marginal) / as.numeric(t(w) %*% S %*% w)
}

w_eq <- setNames(rep(1 / N, N), colnames(Re))
round(sort(risk_contribution(w_eq, S), decreasing = TRUE)[1:5], 4)
#> EU_equity CH_equity UK_equity JP_equity EU_credit 
#>    0.1367    0.1098    0.1066    0.0813    0.0769

Sixteen equally weighted series, and the largest contributes 13.7% of the risk against 6.2% of the capital. Equal capital is not equal risk, and nobody who has looked at a decomposition expects it to be.

14.1.2 Equal risk contribution, and how to get it

The portfolio in which every asset contributes the same share of variance has no closed form, but it has a fixed point that converges in milliseconds.

erc <- function(S, tol = 1e-12, max_iter = 1e5) {
  N <- ncol(S)
  w <- rep(1 / N, N)
  for (i in seq_len(max_iter)) {
    marginal <- as.numeric(S %*% w)
    w_new <- (1 / marginal) / sum(1 / marginal)   # down-weight what contributes most
    if (max(abs(w_new - w)) < tol) break
    w <- w_new
  }
  setNames(w, colnames(S))
}

w_erc <- erc(S)
c(max_deviation_from_equal = max(abs(risk_contribution(w_erc, S) - 1 / N)))
#> max_deviation_from_equal 
#>       0.0000000000002838

Six lines, and the risk contributions are equal to machine precision. Remember that number when the next section spends twenty thousand function evaluations getting nowhere near it.

round(sort(w_erc, decreasing = TRUE)[1:6], 4)
#>    US_government        US_credit    JP_government    UK_government 
#>           0.2360           0.0903           0.0771           0.0634 
#> GLOBAL_commodity        JP_credit 
#>           0.0632           0.0573

US_government still receives the largest allocation — 23.6% — because it is the quietest series and equalising risk means over-weighting quiet assets. But that is a long way from the 84% that minimum variance gives it.

14.1.3 And the approximation that is nearly free

If every pairwise correlation were the same, equalising risk would be exactly inverse-volatility weighting. Correlations here are not equal, but they are not wild either.

base <- portfolio.spec(assets = colnames(Re)) |>
  add.constraint(type = "full_investment") |>
  add.constraint(type = "long_only")

# Exported, and rarely used. Note that it wants the portfolio object as well as
# the returns, and returns a full optimize.portfolio object rather than a vector.
w_iv <- inverse.volatility.weight(Re, base)$weights
w_iv <- w_iv[colnames(Re)]

c(l1_distance_from_erc = sum(abs(w_iv - w_erc)) / 2,
  weight_correlation   = stats::cor(w_iv, w_erc),
  max_rc_deviation     = max(abs(risk_contribution(w_iv, S) - 1 / N)))
#> l1_distance_from_erc   weight_correlation     max_rc_deviation 
#>              0.12011              0.92174              0.02846

inverse.volatility.weight() is exported by PortfolioAnalytics and almost nobody knows it is there. It lands within 0.12 of the exact answer in L1 terms, with a weight correlation of 0.92, for the cost of one division.

14.2 How to actually do it

The package has a purpose-built objective for this. It accepts the problem, scores it correctly, and cannot solve it.

rb_spec <- base |>
  add.objective(type = "risk_budget", name = "StdDev", min_concentration = TRUE)

14.2.1 The objective is right

Before blaming a solver, check what it was asked to minimise. PortfolioAnalytics exposes its own objective function, so we can score two portfolios by hand:

score <- function(w) {
  constrained_objective(w = as.numeric(w), R = Re, portfolio = rb_spec,
                        trace = TRUE, normalize = FALSE)$out
}
c(equal_weight = score(w_eq), true_erc = score(w_erc))
#>         equal_weight             true_erc 
#> 1.769263529070501439 0.000000000000001084

1.769 at equal weights and exactly 0.0 at the true answer. The objective is not misspecified — it knows precisely which portfolio it wants.

14.2.2 The search does not find it

set.seed(1602)

attempt <- function(method, ...) {
  o <- try(suppressWarnings(
    optimize.portfolio(Re, rb_spec, optimize_method = method,
                       trace = FALSE, ...)), silent = TRUE)
  if (inherits(o, "try-error")) {
    return(tibble::tibble(solver = method, l1_from_erc = NA_real_,
                          max_rc_dev = NA_real_, is_equal_weight = NA))
  }
  w <- extractWeights(o)[colnames(Re)]
  tibble::tibble(solver = method,
                 l1_from_erc = sum(abs(w - w_erc)) / 2,
                 max_rc_dev  = max(abs(risk_contribution(w, S) - 1 / N)),
                 is_equal_weight = isTRUE(all.equal(as.numeric(w), rep(1 / N, N),
                                                    tolerance = 1e-6)))
}

searches <- dplyr::bind_rows(
  attempt("DEoptim", search_size = 20000,  traceDE = 0),
  attempt("DEoptim", search_size = 200000, traceDE = 0),
  attempt("random",  search_size = 20000),
  attempt("pso"),
  attempt("GenSA")
)
#>  [1] 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625
#> [11] 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625
#>  [1] 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625
#> [11] 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625

Three of the five return the equal-weighted portfolio exactly — the point every one of them starts from. Ten times the evaluation budget changes nothing. pso does move, and moves further from the answer than standing still would have been.

Put beside the objective values, this is the whole finding: the search sits at a score of 1.77 for two hundred thousand evaluations while a portfolio scoring 0.0 exists and is reachable by six lines of arithmetic.

The one-line approximation is closer to the answer than the twenty-thousand evaluation search. That is the sentence this chapter exists to make possible, and it is not a statement about risk parity — it is a statement about reaching for a search when a fixed point will do.

14.2.3 What the machinery does do

The objective is not useless. Ask it for a cap rather than an equalisation and it delivers:

set.seed(1602)
capped <- optimize.portfolio(
  Re, base |> add.objective(type = "risk_budget", name = "StdDev", max_prisk = 0.15),
  optimize_method = "DEoptim", search_size = 20000, trace = FALSE, traceDE = 0)
#>  [1] 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625
#> [11] 0.0625 0.0625 0.0625 0.0625 0.0625 0.0625

w_cap <- extractWeights(capped)[colnames(Re)]
c(largest_risk_contribution = max(risk_contribution(w_cap, S)), cap = 0.15)
#> largest_risk_contribution                       cap 
#>                    0.1367                    0.1500

A ceiling on any single risk contribution is a constraint the search can satisfy by rejection: it only has to recognise a violation, not find an optimum. Use the risk-budget objective for budgets and bounds. Compute equal risk contribution directly.

14.3 What else is in there

HHI() and diversification() are exported and take a weight vector, so any portfolio in this book can be audited for concentration in one line — including one returned by a solver that ignored its constraint (Section 13.2).

effective_bets <- function(w) {
  r <- risk_contribution(w, S); r <- r[r > 0]
  exp(-sum(r * log(r)))                      # the entropy of the risk shares
}

w_mv <- extractWeights(optimize.portfolio(Re,
  base |> add.objective(type = "risk", name = "var"), optimize_method = "ROI"))[colnames(Re)]

conc <- tibble::tibble(
  portfolio = c("equal weight", "inverse volatility", "equal risk contribution",
                "minimum variance"),
  HHI  = c(HHI(w_eq), HHI(w_iv), HHI(w_erc), HHI(w_mv)),
  div  = c(diversification(w_eq), diversification(w_iv),
           diversification(w_erc), diversification(w_mv)),
  bets = c(effective_bets(w_eq), effective_bets(w_iv),
           effective_bets(w_erc), effective_bets(w_mv)),
  vol  = c(p_vol(w_eq), p_vol(w_iv), p_vol(w_erc), p_vol(w_mv))
)

14.4 Why it works

14.4.1 What risk parity buys, and what it costs

Read the last two rows of Table 14.3 together. Minimum variance achieves 4.14% volatility with 1.8 effective bets out of sixteen. Equal risk contribution achieves 6.70% with exactly 16.

That is the trade, stated in its own units: sixty per cent more volatility for nine times the number of independent bets. Whether it is worth taking depends on how much you trust the covariance matrix that produced the minimum-variance answer — and Section 9.4 measured that: resample the same history and the minimum-variance portfolio moves by five per cent of itself, so its concentration is at least stable.

Out of sample, inverse volatility earns a Sharpe ratio of 0.366 against minimum variance’s 0.360 and equal weighting’s 0.387 (Section 24.4), at less than half the turnover of the optimiser. The risk-based portfolios are not better. They are competitive, cheaper, and much easier to explain to whoever has to sign for them.

14.4.2 The covariance is a regime variable

There is one thing risk parity cannot escape, and it is the same thing that undermines everything else in this book. The number of effective bets is not a property of the portfolio; it is a property of the covariance matrix, and that moves.

Section 3.4 measured it directly: the first principal component’s share of the risky sixteen rises from 0.385 in calm months to 0.602 in crisis, and the effective number of bets falls from 7.05 to 3.98. A portfolio constructed to hold sixteen equal risk contributions in a calm sample holds fewer than four independent bets when it matters.

Risk parity does not solve that. It measures risk more honestly than capital weighting does, and then allocates against an estimate that halves precisely when the allocation is tested. Section 19.1 is where that gets confronted rather than noted.

Exercises

  1. Run the fixed-point erc() on a covariance matrix estimated from calm months only, then apply the resulting weights to the crisis months. How equal are the realised risk contributions?
  2. inverse.volatility.weight() ignores correlations entirely. Construct a universe where that is catastrophic — two nearly identical series and one independent one — and report the risk contributions it produces.
  3. Repeat Table 14.1 with a max_prisk objective instead of min_concentration. Do the solvers agree with each other? Does the budget bind?
  4. The effective-bets measure uses entropy. Replace it with 1 / sum(rc^2), the inverse Herfindahl of the risk shares, and recompute Table 14.3. Which portfolios change rank, and which measure would you defend to a client?
