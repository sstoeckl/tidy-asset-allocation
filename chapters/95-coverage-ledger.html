Appendix F — Coverage Ledger

PortfolioAnalytics exports 115 functions. This appendix walks that namespace against the book’s own source files and records, for every export, the chapters whose code calls it. It is generated at render time from chapters/*.qmd, so it cannot fall behind the text. A capability with no chapter is either a deliberate omission or an oversight, and the table forces the distinction: the omissions are listed at the end with their reasons.

exports <- sort(getNamespaceExports("PortfolioAnalytics"))
files   <- list.files("chapters", pattern = "^[0-9]{2}-.*[.]qmd$", full.names = TRUE)
files   <- files[!grepl("/9[0-9]-", files)]          # narrative chapters only
chapter_of <- function(f) sub("^([0-9]{2}).*$", "\\1", basename(f))

# Code inside chunks and inline expressions; prose mentions in code font are
# excluded, because naming a function is not using it.
code_of <- function(f) {
  x <- readLines(f, warn = FALSE, encoding = "UTF-8")
  fence <- cumsum(grepl("^```", x)) %% 2 == 1
  chunks <- x[fence & !grepl("^```", x)]
  inline <- unlist(regmatches(x, gregexpr("`r [^`]*`", x)))
  paste(c(chunks, inline), collapse = "\n")
}
code <- setNames(lapply(files, code_of), vapply(files, chapter_of, character(1)))

uses <- lapply(exports, function(fn) {
  pat <- paste0("(?<![A-Za-z0-9_.])", gsub(".", "[.]", fn, fixed = TRUE), "\\s*\\(")
  names(code)[vapply(code, function(s) grepl(pat, s, perl = TRUE), logical(1))]
})
ledger <- tibble::tibble(
  export   = exports,
  chapters = vapply(uses, function(u) paste(u, collapse = ", "), character(1)),
  n        = lengths(uses)
)
c(exports = nrow(ledger), used = sum(ledger$n > 0), unused = sum(ledger$n == 0))
#> exports    used  unused 
#>     115      52      63

What is not covered, and why

14 of the 63 unused exports are the _v1 and _v2 legacy shims kept for backward compatibility (add.objective_v1, add.objective_v2, constrained_objective_v1, constrained_objective_v2, constraint_v1, constraint_v2, optimize.portfolio.rebalancing_v1, optimize.portfolio_v1, optimize.portfolio_v2, random_portfolios_v1, random_portfolios_v2, randomize_portfolio_v1, randomize_portfolio_v2, update_constraint_v1tov2); the book uses the unsuffixed functions throughout, as Section 1.2 explains.

The remaining 49 are backtest.plot, box_constraint, center, chart.Concentration, chart.EfficientFrontierCompare, chart.EfficientFrontierOverlay, chart.RiskBudget, constraint, constraint_ROI, custom.covRob.MM, custom.covRob.Rocke, custom.covRob.TSGS, diversification_constraint, extractEfficientFrontier, factor_exposure_constraint, fn_map, generatesequence, group_constraint, insert_objectives, is.constraint, is.objective, is.portfolio, leverage_exposure_constraint, meancsm.efficient.frontier, meaneqs.efficient.frontier, meanrisk.efficient.frontier, meanvar.efficient.frontier, minmax_objective, MycovRobMcd, MycovRobTSGS, objective, opt.outputMvo, optimize.portfolio.parallel, plotFrontiers, portfolio_risk_objective, position_limit_constraint, random_walk_portfolios, randomize_portfolio, return_constraint, return_objective, risk_budget_objective, rp_transform, scatterFUN, transaction_cost_constraint, turnover_constraint, turnover_objective, var.portfolio, weight_concentration_objective, weight_sum_constraint. Each is either an internal helper that the package exports for its own use (fn_map(), rp_transform(), generatesequence(), scatterFUN(), the constrained_objective*() family and objective()/constraint() constructors that add.objective() and add.constraint() call), a plotting wrapper superseded by a chapter’s own figure, or a capability the book declines on purpose. The declines are recorded here so that an omission cannot be mistaken for an oversight: EntropyProg() and the centroid.complete.mc()/centroid.sectors() variants beyond those chapter 17 demonstrates, and random_walk_portfolios(), which draws weights with no feasible-set structure and is dominated for every purpose in the book by rp_sample(), rp_simplex() and rp_grid() (Section 28.2). If a name appears in this list that the reader expected to find in a chapter, that is the place to say so.
