Appendix G — Solutions to Exercises

Every chapter closes with exercises, and this appendix answers them. The solutions are written beside the chapters and run on the same data, so each number below is computed at render time rather than copied from a chapter; a solution that stops running stops the render. Chapters are listed in order, and a chapter absent from this appendix has no exercises yet.

Chapter 1: Setting Up Your Environment

G.0.0.1 Exercise 1

Both routes produce the same matrix, but only one of them needs a check afterwards. merge() aligns two xts objects on their indices and pads any date that one side lacks, so the assertion that nothing was padded is a separate step. Binding the long tables first and crossing once leaves nothing to align: a single as_xts_pm() call sees every date and every asset at once, and a missing cell would be padded and announced by the coercion itself.

MM <- as_xts_pm(sim_money_market_monthly, date, class, return)

stopifnot(ncol(wide_route) == 21L, nrow(wide_route) == 372L, !anyNA(wide_route))

G.0.0.2 Exercise 2

Dropping the early JP_equity rows leaves one column short by the number of months removed. complete.obs discards those months for every series; pairwise.complete.obs keeps them for every pair that has them. A pairwise matrix is not guaranteed to be positive definite, which is why the smallest eigenvalue is worth reading. PortfolioAnalytics uses the pairwise estimate for a variance objective.

trimmed <- sim_class_returns_monthly |>
  dplyr::filter(!(class == "JP_equity" & tidypm::model_year(date) <= 3L))
R_trim <- suppressWarnings(as_xts_pm(trimmed, date, class, return))
R_trim <- R_trim[, colnames(R)]                  # restore the column order by name

range(colSums(!is.na(R_trim)))
#> [1] 336 372
S_complete <- stats::cov(R_trim, use = "complete.obs")
S_pairwise <- stats::cov(R_trim, use = "pairwise.complete.obs")
differ   <- abs(S_complete - S_pairwise) > 1e-12
jp_cells <- outer(colnames(R) == "JP_equity", colnames(R) == "JP_equity", "|")
min_eig  <- min(eigen(S_pairwise, symmetric = TRUE)$values)
stopifnot(all((!differ) == jp_cells))            # the agreeing cells are exactly JP_equity's
c(entries_differing = sum(differ), entries_total = length(differ),
  jp_entries_differing = sum(differ & jp_cells), smallest_eigenvalue = min_eig)
#>    entries_differing        entries_total jp_entries_differing 
#>       225.0000000000       256.0000000000         0.0000000000 
#>  smallest_eigenvalue 
#>         0.0000008627

225 of the 256 entries differ, and the 31 that agree are exactly the JP_equity row and column: both estimators use the same 336 months there, while for every other pair complete.obs discards 36 months that the series never lacked and the pairwise estimate keeps them. The pairwise matrix is positive definite here, with a smallest eigenvalue of 8.6e-07; that is a property of this gap, not a guarantee.

G.0.0.4 Exercise 1

The hedge is the subtraction of Equation 2.4, applied series by series with the exchange rate of the series’ own region. Building the result as one data frame, one row per series, keeps a bond from being paired with another region’s currency.

fx <- sim_fx_monthly
foreign <- setdiff(colnames(R), grep("^(US|GLOBAL)_", colnames(R), value = TRUE))

hedge_table <- dplyr::bind_rows(lapply(foreign, function(s) {
  region <- sub("_.*$", "", s)
  f <- fx[fx$region == region, ]
  stopifnot(all(f$date == as.Date(zoo::index(R))))
  u <- as.numeric(R[, s])
  tibble::tibble(series = s, kind = sub("^[^_]+_", "", s),
                 unhedged = ann_vol(u), hedged = ann_vol(u - f$fx_return),
                 removed = 1 - stats::var(u - f$fx_return) / stats::var(u),
                 currency = ann_vol(f$fx_return),
                 local_with_fx = stats::cor(u - f$fx_return, f$fx_return))
}))

  dplyr::group_by(kind) |>
  dplyr::summarise(dplyr::across(c(unhedged, hedged, removed, currency), mean),
                   .groups = "drop")
by_kind |> dplyr::mutate(dplyr::across(-kind, ~ round(.x, 3)))
#> # A tibble: 3 × 5
#>   kind       unhedged hedged removed currency
#>   <chr>         <dbl>  <dbl>   <dbl>    <dbl>
#> 1 credit        0.123  0.062   0.743    0.098
#> 2 equity        0.192  0.186   0.053    0.098
#> 3 government    0.102  0.038   0.853    0.098

removed <- setNames(by_kind$removed, by_kind$kind)
hedged  <- setNames(by_kind$hedged, by_kind$kind)
jp      <- hedge_table[hedge_table$series == "JP_equity", ]

Hedging removes on average 85% of a foreign government bond’s variance and 74% of a foreign credit class’s, and 5% of a foreign equity market’s. A bond’s local return is a few percent a year of yield and curve movement, a hedged volatility of 3.8% for the government classes, so the currency’s swings of 10% a year dominate the dollar return. An equity market’s local volatility, 19% on average, is already 1.9 times the currency’s, and in Japan the local market tends to rise when the yen falls, a correlation of -0.39, so the two partly cancel before any hedge is applied and hedging raises the volatility of JP_equity from 19.6% to 21.2%. Currency is therefore a property of the asset rather than of the country, and Section 4.3 develops the point.

lo_factor <- function(v, q) {
  rho <- stats::acf(as.numeric(v), lag.max = q - 1, plot = FALSE)$acf[-1]
  q / sqrt(q + 2 * sum((q - seq_len(q - 1)) * rho))

direct <- function(v, q) {

G.0.0.9 Exercise 3

The subtraction is the same; the answer is not.

Hedging JP_equity raises its volatility, from 19.6% to 21.2%. By the decomposition \(\operatorname{Var}(R^{\$}) = \operatorname{Var}(R^{\text{loc}}) + \operatorname{Var}(f) + 2\operatorname{Cov}(R^{\text{loc}}, f)\), the hedge removes the last two terms, and it can only add volatility when the covariance is negative and large enough to outweigh the currency’s own variance. That is the case for Japan, where the covariance is -0.0085 on an annualized basis: the market rises when the yen falls, so the currency is a hedge that the investor already holds, and a forward contract removes it. For a government bond the local return is small and nearly uncorrelated with the currency, so the currency’s variance is most of the total and the hedge removes most of the risk.

Averaging those corners produces a portfolio of 4 classes whose return at the sample moments, 12.4%, lies below the highest sample mean of 13.4%. The right end of a resampled frontier is therefore never the maximum-return portfolio of the sample; it is inside the hull by construction, which is the part of Scherer (2002)’s critique that needs no distributional argument at all.
