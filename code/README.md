# Tidy Asset Allocation in R — the code

One R script per chapter with the chapter's code in the order it runs in the
book, an exercise file with room to work, and the solutions where the book has
them. Everything runs on the modeled market that ships with the companion
package, so no data download is needed.

1. Run `00-setup.R` once. It installs the CRAN packages and the book's pinned
   builds from GitHub.
2. Open any chapter script and run it from this folder (`_common.R` and
   `tables/` sit beside it).
3. Work the exercises in `NN-slug-exercises.R`; compare with the solutions.

The book is at <https://www.tidy-pm.com/dev/>. Generated by `tools/build-code.py` from the book's
source; the scripts are derived files, so report a problem against the book.
